# E-02 会話の最初に出るあいさつ文を変えたい

## 変更依頼

> 会話の最初に出るあいさつ文を変えたい

変更前: `Hello! I'm 社内問い合わせ窓口. How can I help you today?`

## スキルで実現できたか

**できない。**

あいさつ文は利用者が何か話しかける前に表示される。オーケストレーションはまだ動いていないため、スキルが起動する余地がない。スキルは「利用者のメッセージに対して」起動する仕組みなので、発話前の固定文言には原理的に効かない。

## どこを編集したか

Copilot Studio の設定画面である。

**[...]** > **[設定]** > **[あいさつとプロンプト]** > **[あいさつメッセージ]**

同じ画面に **[推奨プロンプト]** もある。これも会話開始前に表示されるものなので、同じくスキルの管轄外である。

Microsoft Learn にも、GitHub Copilot ハーネスの設定項目として記載がある。

> **Greeting message**: Enter the first message users see when they start a conversation.
> (Settings > Greeting & prompts)

## 実際に変更した内容

```
社内問い合わせ窓口です。人事、総務、情報システムに関するご質問にお答えします。ご用件をどうぞ。
```

設定ダイアログで **[完了]** を選んだあと、**[保存]** が必要である。ダイアログを閉じただけでは反映されない。保存後、プレビューの **[新しいチャット]** で変更が確認できた。

ダイアログの冒頭には「設定の変更は、エージェントを保存して公開した後に反映されます。」と表示される。プレビューでは保存だけで反映されたが、利用者が使うチャネルに出すには公開が必要である。

## 判定

**否 (スキルでは実現できない)**

これは失敗ではなく、**境界が判明したという結果**である。

## この検証への影響

あいさつ文は、**「Copilot Studio で文面を書かない」という方針が成立しない箇所**である。正本を外に置いても、この 1 行だけは Copilot Studio の設定画面に直接書くことになる。

| 変更の種類 | 中身を決める場所 | Copilot Studio での作業 |
| --- | --- | --- |
| 知識を足す、直す | SharePoint の `published` | なし |
| 振る舞いを変える | 正本の `SKILL.md` | ファイルを差し替えるだけ |
| 部門を増やす | 正本の指示と説明文 | エージェントの作成、接続、公開 |
| **あいさつ文を変える** | **なし (正本に置けない)** | **設定画面に直接書く** |

対処の方向は 2 つある。

1. あいさつ文の文面も正本に置き、`agents/hub/greeting.md` のようなファイルとして管理する。Copilot Studio へは人がコピーして貼る。差分は追えるが、反映は手作業になる。
2. あいさつ文は管理対象から外す。変更頻度が低く、1 行で済むなら現実的な割り切りである。

どちらを取るかは、あいさつ文をどれくらいの頻度で変えるかによる。手順書には両方を書き、既定は 1 とする。

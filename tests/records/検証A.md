# 検証 A 口調 (v1 から v2)

差し替えたスキル: `tone-and-format`
差し替えたエージェント: ハブ (社内問い合わせ窓口) / 人事 / 総務 の 3 つすべて
実施日: 2026-09-22

v2 での変更点:
- 回答を「結論」「根拠」「次にすること」の 3 見出しで組み立てることを必須にした
- 項目が 2 つ以上あり、それぞれに値や区分があるときは箇条書きではなく表にすることを追加
- 「次にすること」は番号付きで最大 3 つ、申請先と期限が分かっているときは必ず含めることを追加

## A-01 有給は半日単位で取れますか

- 想定: 3 見出しが出て、根拠が表になる
- 起動したスキル: `tone-and-format`

- 回答の要点: 結論、根拠、次にすることの 3 見出しが出た。根拠は表。午前と午後の区分、3 営業日前などの事実はベースラインと一致
- 所見: 差し替えがそのまま効いた回。

## まとめ

- 判定: **合格 (条件付き)**。4 問中 2 問でのみ 3 見出しが出た
-指示は 1 度も編集していない
- 事実 (日数、金額、期限、条文番号) は 4 問とも正しく、差し替えの前後で変わっていない
- 割れた原因は、この時点では分からなかった。A-02 と A-03 で使われなかったのは、ハブ自身の `tone-and-format` である
